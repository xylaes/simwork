# SimWork | The Experience Sandbox

> **Solving the entry-level "0 years of experience" Catch-22.**  
> An interactive workplace simulation platform where candidates solve authentic operational crises, undergo realistic AI executive evaluations, and generate verified **Proof Dossiers** with ATS-optimized resume bullet points.

---

## 🎯 The Core Concept
The modern entry-level job search is broken. Candidates submit hundreds of resumes into ATS black holes, while companies refuse to hire juniors without 2–3 years of experience.

**SimWork bypasses this divide**:
1. **The Scenario**: Candidates are dropped into an active simulated workplace sprint (e.g., *Associate Operations Analyst at Apex Global Logistics*).
2. **The Incident**: An urgent briefing from leadership (*Sarah Lin, VP of Regional Operations*) regarding an 8.2% margin collapse despite an 11.8% volume increase.
3. **The Data Audit**: Candidates analyze 40+ raw dispatch records, isolating 3rd-party spot-freight markups (+68% premium), cross-dock detention bottlenecks (3.2hr avg dwell), and unhedged fuel surcharge lags.
4. **The Executive Review**: An interactive AI evaluation engine reviews the submitted Executive Operations Memo, providing authentic pushback, critique, and a strategic stress test.
5. **The Proof Dossier**: Successful completion generates a public, verifiable proof page and quantifiable, ATS-ready resume bullet points.

---

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React, Canvas Confetti
- **Build Tool**: Vite 6
- **Evaluation Engine**: Dual-mode (Smart built-in evaluator + optional live Google Gemini API)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/<your-username>/simwork.git
cd simwork
npm install
npm run dev
```

Visit `http://localhost:5173/` in your browser.
